## Local setup

Select the guide relevant to your development machine and follow the steps carefully to get a clean working environment ready.

| Operating System | Android                                          | iOS                                                                     | Linux                                                                                        |
| ---------------- | ------------------------------------------------ | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Windows          | :white_check_mark: [Setup Guide](/setup/windows) | :x: Unsupported                                                         | :x: Unsupported                                                                              |
| macOS            | :white_check_mark: [Setup Guide](/setup/macos)   | :white_check_mark: [Setup Guide](/setup/macos#setting-up-macos-for-ios) | :x: Unsupported                                                                              |
| Linux            | :white_check_mark: [Setup Guide](/setup/linux)   | :x: Unsupported                                                         | :construction: [Setup Guide](/setup/linux#setting-up-linux-for-linux-desktop) (experimental) |

:::warning A note about iOS on unsupported systems

A Mac is required to build projects that use native iOS code. Simpler apps can be tested using [NativeScript Preview](https://preview.nativescript.org).

:::

:::warning A note about Linux on unsupported systems

A Linux machine (x64 or arm64) is required to build projects for the Linux desktop target. The Linux platform is currently experimental, see [Developing for Linux](/guide/linux/).

:::
